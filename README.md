# 8W MIC Speaker PCB

This project is an 8 Watt MIC Speaker PCB designed using DesignSpark PCB software.

## Features
- 8W audio amplifier circuit
- Microphone input support
- PCB layout design
- Through-hole component design

## Software Used
- DesignSpark PCB

## Project Files
- Schematic files (.sch)
- PCB layout files (.pcb)
- Drill files (.drl)
- Plot report
- PDF PCB output

## Applications
- Audio amplification
- DIY speaker systems
- Electronics learning projects
